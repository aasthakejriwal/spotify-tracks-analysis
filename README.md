# Spotify Tracks Data Analysis and Visualization

## Project Overview
This project explores a Spotify tracks dataset using Python to understand music characteristics, track popularity, and relationships between audio features.

## Objectives
- Analyze the popularity of Spotify tracks.
- Identify tracks with high popularity scores.
- Compare average popularity across music genres.
- Explore relationships between danceability, energy, valence, and popularity.
- Study track duration and explicit versus non-explicit tracks.
- Visualize correlations between audio features.

## Dataset
The dataset contains information about Spotify tracks, including track names, artists, popularity, duration, genre, danceability, energy, loudness, acousticness, valence, and other audio features.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- GitHub

## Data Analysis and Visualizations
The project includes eight visualizations:
1. Distribution of track popularity
2. Top 10 most popular tracks
3. Top 10 genres by average popularity
4. Danceability versus popularity
5. Energy versus valence
6. Correlation heatmap of audio features
7. Distribution of track duration
8. Explicit versus non-explicit tracks

## Conclusion
This project uses data analysis and visualization to explore patterns in Spotify music data. The results help illustrate how track characteristics and audio features vary across songs and genres. Correlation analysis is used to examine relationships between variables, without assuming that correlation proves causation.
